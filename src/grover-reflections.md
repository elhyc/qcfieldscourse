# Grover Reflections Applet

This applet shows the two reflections that make up one Grover operator:
the oracle reflection across the bad axis, followed by the diffusion
reflection across the equal superposition state.

</iframe>

Use the stage buttons to step through `State -> Oracle -> Diffusion -> State`.
